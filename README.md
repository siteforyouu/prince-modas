# Prince Modas — loja em arquivo único

O site completo está em `index.html` e inclui CSS, JavaScript e imagens incorporadas.

## Publicar no GitHub Pages

No GitHub, abra **Settings → Pages**. Em **Build and deployment**, selecione **Deploy from a branch**, escolha `main` e `/ (root)`, depois clique em **Save**. O Pages não foi configurado automaticamente.
